کامپیوتر

Computer

آشنایی با اجزای اصلی سخت‌افزار و نرم‌افزار کامپیوتر — هر کارت را بررسی کنید تا مفاهیم پایه را بهتر درک کنید.

Learn about the main hardware and software components of a computer — explore each card to better understand the fundamentals.

RAM

حافظه موقت (Random Access Memory) فضایی است که سیستم برای اجرای برنامه‌ها و نگهداری داده‌های در حال استفاده از آن بهره می‌برد. هرچه RAM بیشتر باشد، سیستم روان‌تر کار می‌کند و می‌تواند برنامه‌های بیشتری را همزمان اجرا کند.

Random Access Memory is the temporary space the system uses to run programs and hold active data. More RAM means smoother performance and the ability to run more applications at the same time.

CPU

پردازنده مرکزی (Central Processing Unit) مغز کامپیوتر است. تمام دستورات را دریافت، پردازش و اجرا می‌کند. سرعت و تعداد هسته‌های CPU تأثیر مستقیمی روی عملکرد کلی سیستم دارد.

The Central Processing Unit is the brain of the computer. It receives, processes and executes all instructions. CPU speed and core count directly affect overall system performance.

GPU

پردازنده گرافیکی (Graphics Processing Unit) مسئول پردازش تصویر، ویدیو و محاسبات موازی است. در بازی‌ها، رندر سه‌بعدی، ویرایش ویدیو و حتی هوش مصنوعی نقش کلیدی دارد.

The Graphics Processing Unit handles image, video and parallel computing tasks. It plays a key role in gaming, 3D rendering, video editing and even artificial intelligence.

SSD و HDD

SSD & HDD

SSD (Solid State Drive) سرعت بسیار بالاتری نسبت به HDD دارد و بدون قطعه متحرک کار می‌کند. HDD ارزان‌تر است و ظرفیت بالاتری ارائه می‌دهد. انتخاب درست بستگی به نیاز و بودجه شما دارد.

SSD offers far higher speed than HDD and has no moving parts. HDD is cheaper and provides larger capacity. The right choice depends on your needs and budget.

Motherboard

مادربورد مرکز اتصال تمام قطعات سخت‌افزاری است. پردازنده، حافظه، کارت گرافیک و سایر قطعات از طریق مادربورد با هم ارتباط برقرار می‌کنند. انتخاب مادربورد مناسب برای ارتقا و سازگاری آینده مهم است.

The motherboard is the central hub connecting all hardware components. CPU, memory, graphics card and other parts communicate through it. Choosing the right board matters for future upgrades and compatibility.

Windows

ویندوز یکی از پرکاربردترین سیستم‌عامل‌هاست. یادگیری نکات کاربردی، تنظیمات مهم و عیب‌یابی ساده می‌تواند تجربه استفاده شما را بسیار بهتر کند و مشکلات روزمره را کاهش دهد.

Windows is one of the most widely used operating systems. Learning practical tips, key settings and simple troubleshooting can greatly improve your experience and reduce everyday issues.

آشنایی با مفاهیم پایه و ابزارهای مدرن هوش مصنوعی — از تعریف ساده تا کاربردهای واقعی.

Introduction to core concepts and modern AI tools — from simple definitions to real-world applications.

هوش مصنوعی چیست؟

What is AI?

هوش مصنوعی به سیستم‌هایی گفته می‌شود که می‌توانند کارهایی شبیه به هوش انسان انجام دهند؛ مثل یادگیری، تصمیم‌گیری و حل مسئله. امروز AI در گوشی، جستجو، پیشنهاد محتوا و بسیاری از ابزارهای روزمره حضور دارد.

Artificial Intelligence refers to systems that can perform tasks similar to human intelligence — learning, decision-making and problem-solving. Today AI is present in phones, search, content recommendations and many everyday tools.

Machine Learning چیست؟

What is Machine Learning?

یادگیری ماشین شاخه‌ای از AI است که در آن سیستم‌ها از داده یاد می‌گیرند و بدون برنامه‌نویسی صریح، الگوها را کشف می‌کنند. این فناوری پایه بسیاری از پیشنهادگرها، تشخیص تصویر و پیش‌بینی‌هاست.

Machine Learning is a branch of AI where systems learn from data and discover patterns without explicit programming. It powers recommenders, image recognition and many prediction systems.

Generative AI چیست؟

What is Generative AI?

هوش مصنوعی مولد می‌تواند محتوای جدید بسازد؛ از متن و تصویر تا صدا و کد. مدل‌هایی مثل ChatGPT و ابزارهای تولید تصویر نمونه‌های معروف این فناوری هستند که خلاقیت را دگرگون کرده‌اند.

Generative AI can create new content — text, images, audio and code. Models like ChatGPT and image generators are well-known examples that have transformed creativity.

ChatGPT چیست؟

What is ChatGPT?

ChatGPT یک مدل زبانی پیشرفته است که می‌تواند مکالمه کند، سؤال پاسخ دهد، متن بنویسد و در یادگیری و کار کمک کند. آشنایی با نحوه سؤال پرسیدن از آن، نتیجه را بسیار بهتر می‌کند.

ChatGPT is an advanced language model that can converse, answer questions, write text and assist with learning and work. Knowing how to ask good questions greatly improves the results.

Prompt Engineering

هنر نوشتن دستورات (پرامپت) مؤثر برای مدل‌های زبانی. با پرامپت خوب می‌توانید پاسخ‌های دقیق‌تر، خلاقانه‌تر و کاربردی‌تری از AI دریافت کنید. این مهارت امروزه بسیار ارزشمند است.

The art of writing effective instructions (prompts) for language models. Good prompts help you get more accurate, creative and useful responses from AI. This skill is highly valuable today.

ابزارهای کاربردی AI

Useful AI Tools

ابزارهای متنوعی برای تولید متن، تصویر، ویرایش، ترجمه، کدنویسی و مدیریت کار وجود دارند. شناخت ابزار مناسب برای هر نیاز، سرعت و کیفیت کار شما را بالا می‌برد.

There are many tools for text generation, images, editing, translation, coding and task management. Knowing the right tool for each need boosts your speed and quality of work.
